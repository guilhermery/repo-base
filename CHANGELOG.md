# Changelog
--- 
## [1.0.0] - 2026-06-05

### Added

* Adicionado filtro opcional por prioridade na função `filter_tasks`.
* Adicionada documentação das funções através de docstrings.
* Adicionado fluxo de correção emergencial utilizando branch `hotfix/fix-filter`.

### Changed

* Melhorada a exibição das tarefas utilizando indicadores visuais de status (`✓` e `X`).
* Alterado o formato de apresentação das prioridades para letras maiúsculas.
* Atualizada a função `format_task` para exibir informações de forma mais organizada.
* Integradas as alterações desenvolvidas em paralelo pelos membros da equipe através de rebase e merge.

### Fixed

* Corrigido bug proposital introduzido durante a simulação de ambiente de produção.
* Resolvidos conflitos de código gerados pela edição simultânea das funções `format_task` e `filter_tasks`.
